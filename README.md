# Arwin Renardi — Developer Portfolio

Personal portfolio for **Arwin Renardi**, a Flutter-focused developer based in Jakarta, Indonesia. The site presents selected mobile and full-stack work, professional experience, technical skills, education, and contact information in a minimal, recruiter-friendly interface.

## Focus

- Flutter / Dart mobile development
- Riverpod and scalable application architecture
- Firebase and REST API integration
- AWS Cognito / OAuth2 authentication
- Google Play and App Store delivery
- Next.js / TypeScript full-stack development
- Supabase / PostgreSQL and payment integrations

## Selected work

### One Abipraya Mobile
Enterprise Flutter application covering 15+ business modules and 40+ navigable screens. Work included approximately 37 REST API integrations, AWS Cognito SSO, biometric authentication, GPS attendance, payslips, document workflows, notifications, testing, and store releases.

### Cooperative Financial App
Flutter application spanning 14 feature modules, 44 screens, and approximately 78 API paths. The codebase uses feature-first organization with Riverpod and applies Clean Architecture in the purchasing workflow.

### Full-Stack Booking & Payment Platform
Next.js and TypeScript booking platform backed by Supabase/PostgreSQL. Business rules use PostgreSQL RPC and RLS for booking state, role-based access, and slot integrity, with Midtrans server-side payment creation and webhook synchronization.

### Personal Finance Tracker
Flutter/Firebase personal project built with Clean Architecture, feature-first organization, and Riverpod. Features include transactions, budgets, household sharing, bills, dashboards, biometric lock, Firestore real-time sync, Cloud Functions, and FCM reminders.

## Tech stack

- **Framework:** Next.js 16, React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Motion:** Motion
- **Icons:** Phosphor Icons
- **Deployment:** Vercel

## Design principles

The portfolio intentionally uses a restrained visual system: strong typography, generous spacing, subtle borders, limited motion, accessible reduced-motion behavior, and concise project copy. The goal is to keep attention on engineering experience rather than decorative effects.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

For a production check:

```bash
npm run build
npm start
```
